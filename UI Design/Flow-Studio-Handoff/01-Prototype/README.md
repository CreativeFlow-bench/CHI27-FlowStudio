# Prototype

Open `index.html` for English or `index-cn.html` for Chinese.

These files are interaction references. They intentionally run without a build step, server or account.

## Suggested demo

1. Double-click the canvas.
2. Add a library form.
3. Use Brush, Sketch, Pull, Smooth or Add.
4. Review and confirm an inferred intent.
5. Confirm additional intents if needed.
6. Select Diverge.
7. Choose direction terms and generate references.
8. Select a reference to build a new version.
9. Return to an older version and create a branch.

Do not treat generated geometry, model upload or AI inference as implemented production capabilities.
