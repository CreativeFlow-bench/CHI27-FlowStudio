# Flow Studio — 交接说明

一个「意图驱动的三维迭代」界面原型。单文件、无构建、双击即可运行。

- `index.html` — 英文版（主版本，改动先落在这里）
- `index-cn.html` — 中文版（从英文版派生，改完英文再同步）
- `cn/index.html` — 中文版的副本，仅为部署到 `/cn/` 路径用

---

## 产品在解决什么

三维形态很难用语言描述——「再圆润一点」对模型几乎没有信息量。

所以这个工具让用户**在形体上直接做空间操作**（刷选、勾画、拉扯、抹平、加构件），系统持续观察这些动作 + 视角行为（停留、缩放、旋转）+ 可选的文字补充，**推断出用户想要什么**，再把意图展开成解空间去发散。

完整链路：

```
标记 → 意图 → 发散 → 方向 → 生成
 ↑                              │
 └──────── 任何阶段可回跳 ────────┘
```

1. **标记** — 用工具在曲面上操作，留下空间证据
2. **意图** — 全局只有一条 live 推断卡，持续累积所有操作并重写读解；用户点「确认」才锁定，之后再操作会开出新的一条
3. **发散** — 把所有已确认意图合并成一句话（会指出冲突而非取平均），用户可用语言补充
4. **方向** — 解空间按「美学·材质」和「结构·形态」两轴发散关键词，选词后生成 4 张方向参考
5. **生成** — 选定方向后作为新节点长在画布上，父版本右侧；同一父节点再分叉则叠在下方

## 几条不能破坏的不变量

改动时如果动到这些地方，**必须重新验证**。

### 1. 浮层永不遮挡模型与彼此

`clears()` 把三类东西都当障碍：所有模型节点（按 `frameK` 算的框半径）、所有 UI 面板（`uiRects()` 实时读 `getBoundingClientRect`）、已落位的其他卡片。

意图卡沿标记方向做**径向回避**（±15° 扫 26 档 × 5 档距离），失败则网格扫描，再失败按**重叠面积最小**落位（压模型的惩罚权重是压面板的 1.5 倍）。

存档卡多两层兜底：缩小缩略图重试、自动拉远镜头腾空间。

> 曾经的 bug：兜底分支忘了做碰撞检测，直接用固定坐标 → 必然压住模型。

### 2. 模型尺寸是被推导出来的，不是设定的

```js
base = max(170, min(384 * zoom, bandH, bandW - 560))
```

`bandW - 560` 预留了左右两条意图栏。**因为尺寸从可用空间反推，所以任何视口、任何缩放下卡片都不可能压到形体上。** 缩放会自然触顶而不是把模型顶出安全区。

### 3. 三维数学

形变球面网格 18×28，`rot()` / `unrot()` 严格互逆（误差 ~1e-16）。

- 标记存的是**模型空间的方向向量**，不是屏幕坐标 —— 所以旋转时标记跟着曲面走，转到背面自动隐藏
- 屏幕点击 → `pickDir()` 反投影到球面 → 再投影回屏幕，误差 ~1e-14 px
- 背面剔除后可见面约 41%（符合半球预期；若是 59% 说明法线方向反了）
- 五个基础几何体全部归一化到半径 1，端盖顶点顺序为 `[r[j], r[k], c, c]`（写成 `[c, r[j], r[k], c]` 会因首尾同点导致法线为零被误剔除）

### 4. 版本树

`relayout()` 是标准 tidy-tree：叶子占唯一行槽，父节点竖向居中于子节点之间。深度向右（`COL=560`），兄弟向下（`ROW=470`）。

**重叠是结构上不可能的，不是靠避让。** 早期版本只数直接兄弟数、没算子树高度，从旧节点分叉会砸到别人的后代身上。

## 文件结构

单个 `<script>`，按功能分段，段落用 `/* ═══ NAME ═══ */` 标记：

| 段 | 内容 |
|---|---|
| TAXONOMY | 工具、几何体、部件、质量维度、解空间词库（168 词） |
| 3D MESH | 网格生成、旋转、基础几何体 |
| CANVAS / WORLD | 世界变换、绘制、命中测试 |
| CAMERA | 缩放、fit、镜头动画 |
| SAFE FRAME | 安全区计算、面板障碍、卡片落位 |
| POINTER | 所有指针交互的分派 |
| PERCEPTION | 行为日志、注意力模型 |
| TOOLS / PICKER / REFERENCE / COMPOSER | 工具栏、来源选择器、@ 引用、对话框 |
| INTENT | 推断状态机、意图卡渲染 |
| SIDE PANEL | 会话面板、合并意图、解空间 |
| REFS → BUILD | 方向参考、生成新版本 |
| ARCHIVE CARD | 版本存档、分支 |
| FLOW / INIT | 阶段条、初始化 |

## 约定

**术语**：`Object`（整体）/ `Surface`（局部）；意图三态 `INFERRING` → `STATED` → `CONFIRMED`。工具名用建模行业动词：Navigate / Select / Brush / Sketch / Pull / Smooth / Add。

**排版**：三种字体各管一层信息 —— Inter 管界面、Instrument Serif 斜体管标题与品牌、JetBrains Mono 管数值与标签。中文版 serif 走**正体**（合成斜体会让汉字笔画变形），等宽标签字距从 `.14em` 收到 `.05em`。

**面板质感**：一个面板一种色相、一个角落、透明度不超过 13%。感知=蓝紫、决策=琥珀、浏览=青、其余中性。

**说明 vs 操作**：能点的东西有描边和 hover；说明性文字用 `.note`——发丝线 + 排版层级，**不要容器**。

**AI 计算中**：统一用 `thinkHTML()`，并且要说明**在算什么**（几条意图、几个词），不是通用转圈。

**回顾即导航**：任何"在看"的时刻自动切回 Navigate 模式——进入界面、点 Diverge、浏览方向参考、点旧版本。共 6 个触发点。

## 已知限制

- **性能**：每帧重绘所有节点（504 面/个）。超过 8 个版本拖动会掉帧，需要给非活动节点做离屏缓存。
- **上传是假的**：`seedNode()` 按文件名建占位形体，没有真的解析 OBJ/GLTF。要接真模型得引入 three.js。
- **@ 只能选一个参考**：真实使用大概率需要「参考 V2 的底座 + V4 的表面」这种多选 + 部位标注。
- **重新发散会覆盖上一批方向**：按探索树的逻辑，每次生成都应该存档一份。
- **字体依赖 Google Fonts**：断网或墙内会掉字体。已做降级字体栈兜底，彻底解决需要 base64 内嵌。
- **仅桌面**：< 1180px 显示提示页。流程条在 < 1360px 自动收成紧凑态，否则会压到对话框。

## 下一步的建议路径

如果要往产品走，优先级大概是：

1. **拆文件** —— 单文件 2200 行已经到上限了。按上面的分段拆成模块。
2. **接真 3D** —— three.js 换掉手写的投影渲染，同时解决性能和真实模型导入。
3. **意图 → 几何的真实映射** —— 现在生成是随机形态。真做需要把「更轻盈 + 镂空」翻译成实际的网格操作或扩散模型条件。
4. **多参考 + 部位标注** —— @ 功能的自然延伸。

前两步是工程重构，后两步才是这个产品真正的技术难点。
