# Production assets

The current prototype embeds its interface icons and loads Google Fonts remotely.

Before production:

- Decide whether Inter, Instrument Serif and JetBrains Mono may be loaded from Google Fonts.
- If not, add licensed local webfont files here and update the application.
- Export or replace embedded icons using the engineering team's icon system.
- Add representative licensed GLB/GLTF files to `sample-models/`.
- Add direction-reference placeholders only if they are approved for user testing.

No production model or image asset is included in this package.
