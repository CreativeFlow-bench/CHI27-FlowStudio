# DCC 几何操作族 v2：聚类方法与专家编码准备

## 结论

- 原表的 26 个类别被视为候选清单，而不是既定分类。
- 对 159 个软件—工具条目进行原子拆分后得到 203 条功能映射。
- 依据“操作对象 + 底层几何机制 + 主要几何效果”归并为 41 个操作族。
- 尚未填写“语义驱动 / 空间控制驱动 / 人机混合控制 / 后端自动化”；这些是下一轮专家编码变量，不是本轮聚类依据。

## 聚类判据

1. 先拆分复合单元格：一个名称同时包含 Bridge/Fill、Smooth/Remesh 等多个机制时，拆成多个原子功能。
2. 只有当操作对象、底层机制和主要几何效果一致时，才合并为同一操作族。
3. 不按软件菜单位置、图标或相似名称合并。
4. 若同一功能的交互模式会导致不同的人机控制分配，则拆分，例如“笔刷局部平滑”与“算子式全局平滑”。
5. 控制/作用域操作（遮罩、分组、可见性）与直接生成几何的操作分开。

## 这次最重要的拆分

- 吸附 / 对齐 / 约束 → 吸附与轴向约束放置；对齐与包围盒匹配。
- 刀切 / 切片 / 平面切割 → 自由路径切割；平面截切。
- 桥接 / 补面 / 封口 → 边界桥接；洞口填充与封口。
- 合并 / 焊接 / 溶解 → 合并与焊接；溶解与冗余拓扑移除。
- 细分 / 平滑 / 重构网格 → 细分细化；均匀重网格；重拓扑；算子式平滑。
- 镜像 / 对称 → 几何镜像；对称操作复制。
- 扫掠 / 放样 / 蒙皮 → 沿路径扫掠；多截面放样与蒙皮。
- 投射 / 贴合 / 收缩包裹 → 表面贴合；细节投射；其中 Quad Draw 回到重拓扑。
- 雕刻平滑 / 压平 / 放松 → 局部平滑放松；压平刮削抛光。
- 雕刻膨胀 / 收紧 / 刻痕 → 法向膨胀；收紧刻痕强化。
- 遮罩 / 隐藏 / 分离 / 分组 → 遮罩权重；分组选择；可见性；对象分离。

## 边界与限制

- 这是“当前 159 条语料驱动”的操作族，不是穷尽所有 DCC 功能的百科分类。
- 文档证据来自七个软件的官方技术文档；组合名称过宽的条目已标记 Medium/Low confidence。
- 下一步应让专家只编码 41 个操作族，而不是重复判断每个软件的同义工具。
